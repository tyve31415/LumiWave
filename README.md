# LumiWave · 示波器合成器（Electron 桌面版）

用数学公式合成波形的芯片音乐（Chiptune）合成器：16 声部混音 + 多窗口桌面界面 + 大通道路由 + MIDI 自动扒谱 + 时间线编辑器 + 步进音序器 + 录制导出 WAV，基于 **Electron** 构建，重点优化了交互体验与性能。

## 快速开始

```bash
npm install     # 安装依赖（首次会下载 Electron）
npm start       # 启动桌面应用
```

需要 Node.js ≥ 18。Windows 上可直接打包安装包：

```bash
npm run dist    # 生成 NSIS 安装包 + 便携版（输出到 dist/）
```

## 界面：多窗口固定分屏（无页面滚动、无堆叠）

整个界面是一块「桌面」，每个功能模块一个窗口，采用**固定分屏布局**：各窗口位置与大小由预设槽位决定，**绝不重叠堆叠**；应用窗口变大时整体等比铺满，过小时桌面出现滚动条（布局不变）。

每个窗口右上角有 **🔒/🔓 锁定按钮**：

- **锁定（默认）**：窗口不可移动、不可缩放，界面保持整齐
- **解锁**：窗口变为虚线边框，可拖动与八向缩放，交互逻辑参考 VS Code：

**拖动（VS Code 式）**

- 拖动中窗口**抬升悬浮**（半透明、置顶），可暂时从其他窗口上方经过
- 悬停到其他窗口 → 显示四边**分屏停靠高亮**（左/右/上/下半区，绿色预览框）；松开即**停靠分屏**：目标窗口让出半区，两者平分原区域，标题栏出现琥珀色「⧉」徽章
- 停靠关系**联动**：目标窗口移动/缩放时停靠窗口自动跟随重排；拖离即解除
- 空白处松开 → **磁吸吸引**：自动对齐其他窗口边缘或桌面边缘（虚线预览框）
- 落点与其他窗口重叠 → 自动弹回原位

**缩放（VS Code 式）**

- 八向缩放带**磁吸对齐**（吸附到其他窗口边/桌面边）
- 停靠对的**共享边界双向联动**：拖动边界会同时调整两侧窗口尺寸（分割条行为）

窗口可最小化/关闭，顶栏「🪟 窗口」下拉菜单随时重开/聚焦任意窗口（原位置被占用时自动挪到空白处）；位置、大小、锁定、停靠与可见状态自动记忆；菜单底部「▦ 整理全部窗口」一键解除停靠并恢复默认分屏。

```
┌─────────────┬────────────────────────────┬─────────────┐
│ 🗂 收藏夹     │ 📟 主示波器                 │ 🔢 音序器   │
│ · 本地音乐   ├──────────────┬─────────────┤ (CH4)       │
│ (固定栏)    │ 🎹 混音器    │ 🕘 时间线   │             │
└─────────────┴──────────────┴─────────────┴─────────────┘
```

**左列固定栏**：「🗂 收藏夹」与「🎧 本地音乐」已合并为一个窗口（上：文件夹树浏览；下：播放控制），固定在桌面最左列，位置与大小恒定——禁止拖动、缩放、停靠，且**无锁按钮**；步进音序器与它交换位置，位于最右列（可自由调整）。播放器的小波形与频谱以**二级菜单**形式默认折叠，点击「波形 / 频谱」条展开显示。

**顶栏导航与弹出层**：窗口按钮已合并为「🪟 窗口」下拉菜单（按类型聚合，含打开/聚焦状态指示，条目由窗口定义自动生成）；「🎛 通道控制」是**弹出层**——从该菜单打开后悬浮覆盖在其他窗口之上（默认隐藏），**可自由拖动**（位置自动记忆，无锁按钮，禁止缩放与窗口内滚动）；CH1–CH4 每通道占一行（**无默认映射**），点击行展开可勾选该通道由哪些音源**相加**（混音器 / 时间线 / 音乐播放器 / 音序器，多选相加）；点击窗口外任意处或在菜单中再点一次收起。

| 窗口 | 说明 |
| --- | --- |
| 📟 主示波器 | 4 通道示波器：默认 CH1–CH4 各占一栏；窗口顶部 MIX 按钮在「4 个独立通道」与「单个 MIX 通道」显示间切换（波形/频谱切换），5 个旋钮 + 通道图例 |
| 🗂 收藏夹·音乐 | 收藏文件夹、树形浏览、点击即播（CH3）+ 播放控制与波形/频谱二级菜单 |
| 🎛 通道控制 | 弹出层：CH1–CH4 每通道一行，点击展开勾选音源（多选相加），开关 / 合并·独立 / 音量 |
| 🎹 混音器（CH1） | 16 声部合成 + 16 声部示波器 + 双八度钢琴 + 演示曲控制 |
| 🕘 时间线（CH2） | 钢琴卷帘编辑器（独立引擎播放） |
| 🔢 音序器（CH4） | 16 步音序器（独立引擎 + seq-only 门限），位于最右列 |

## 打包分发（Windows）

```bash
npm run dist    # 生成 NSIS 安装包 + 便携版（输出到 dist/）
npm run pack    # 仅生成未打包的目录版（快速验证，不产出安装器）
```

产物（位于 `dist/`）：

| 文件 | 说明 |
| --- | --- |
| `LumiWave Setup 2.0.0.exe` | NSIS 安装包：安装向导、可选安装目录、桌面/开始菜单快捷方式、卸载器 |
| `LumiWave 2.0.0.exe` | 便携版：单文件免安装，双击即用，适合 U 盘分发 |

打包要点：

- 应用图标为 `build/icon.ico`（256×256）；换图标直接替换该文件即可
- 使用教程会随包分发（安装目录 `resources/使用教程.md`，菜单「帮助 → 打开使用教程」）
- 版本号由 `package.json` 的 `version` 决定，发布新版前先改它
- 首次打包会联网下载打包工具链（NSIS 等，缓存在 `%LOCALAPPDATA%\electron-builder\Cache`）
- 未做代码签名：Windows SmartScreen 会提示「未知发布者」，用户点「更多信息 → 仍要运行」即可；正式大规模分发建议购买代码签名证书

## 功能一览

- ▶ 内置演示曲「Funky Stars」（真实 MIDI 转录），也支持导入任意 `.mid` 自动分配 16 声部
- **大通道架构**：CH1–CH4 四条中性输出通道（无默认映射），每条通道 = 用户在通道弹出层勾选的音源之和（混音器 / 时间线 / 音乐播放器 / 音序器，可多选相加）；每通道独立波形、音量与开关，可「合并」进主混音或「独立」（SOLO）单独监听
- 混音器：16 声部，每声部独立波形公式、预设、增益、开关（独立 AudioWorklet）
- 主示波器：4 通道分栏示波器（默认 CH1–CH4 各一栏，顶部 MIX 按钮切换为单个 MIX 通道全屏显示），波形/频谱切换 + 5 个示波器旋钮
- 时间线编辑器（钢琴卷帘，独立引擎）、步进音序器（独立引擎）、双八度钢琴（鼠标 + 电脑键盘）
- 收藏夹：持久化收藏音乐文件夹，树形列出全部音频文件，点击即载入 CH3 播放
- 音频播放器（WAV/MP3/FLAC/OGG）+ 实时波形/频谱
- 录制并导出 WAV：录制「总输出」（含全部通道混合结果）

## 性能优化

- **渲染循环按需工作**：无音频活动时示波器降至低频刷新（保留磷光余晖），页面隐藏/最小化时完全停止绘制
- **网格静态层缓存**：示波器网格只画一次到离屏画布，逐帧仅做位图合成
- **无 shadowBlur 绘制**：主示波器与 16 声部示波器的辉光改用「宽半透明描边 + 细实线」双描边，每帧 GPU 开销大幅下降
- **音频线程隔离**：16 声部求和与函数求值在 AudioWorklet 独立线程，UI 不卡顿
- **WAV 编码在工作线程**：长录音导出不阻塞界面
- **backgroundThrottling 关闭**：窗口失焦时音频与渲染保持流畅

## 安全

- 渲染进程开启 `contextIsolation` + `sandbox`，禁用 `nodeIntegration`
- 预加载脚本仅通过 `contextBridge` 暴露白名单 API
- 页面启用 CSP；IPC 全部校验调用来源
- CSP 的 `script-src` 允许 `'unsafe-eval'`：合成器按需用 `new Function` 编译用户输入的波形公式（产品核心机制），在无 Node 权限、IPC 受校验的沙箱渲染进程内是可控的取舍

# 示波器合成器 · Oscilloscope Synth

一个纯前端的电子合成器 / 芯片音乐（Chiptune）生成网站：在浏览器里用数学公式合成波形，叠加多个声部，内置示波器实时显示波形与频谱，可以演奏、录制并保存曲子。

## 快速开始

无需安装任何软件，直接用浏览器（推荐 Chrome / Edge / Firefox）打开 `index.html` 即可。

- ▶ 播放内置演示曲「Funky Stars」（由真实 MIDI 自动转录而来）
- 在编辑器里写 `f(t)` 波形公式，立刻听到声音
- 多声部叠加，做出一首完整的芯片音乐

## 文件结构

| 文件 | 说明 |

| `song-data.js` | 内置演示曲的 MIDI 转录数据 |
